# Agent Instructions

## Nach Feature-Implementierung
- Linter muss ohne Findings durchlaufen: `cargo clippy --all-targets -- -D warnings`
- Tests müssen erfolgreich durchlaufen: `cargo test`
- Formatierung prüfen: `cargo fmt --check`

## Dateien anlegen
- Neu hinzugefügte Files direkt zum git tracking hinzufügen (`git add <file>`), damit sie nicht als untracked stehen bleiben.

## UI in Englisch
- Die UI muss einheitlich in Englisch sein
